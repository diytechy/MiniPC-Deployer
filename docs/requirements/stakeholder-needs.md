### Amendment 2026-09-12 — the AI-usage feeder's gauge semantics (SN-016, B7)

Owner rulings of 2026-09-12. Spine: NagLight SN-039 amendment and **IF-012
v1.1**. Plan and evidence: HomeHub `GAUGE_RAIL_REDESIGN_PROPOSAL_2026-09-12.md`.

**`ai_usage_feeder.py` changes in three ways.**

1. **Post remaining, not consumed.** `value = 100 − percent` with
   `GAUGE_DIRECTION = "down"` and `target: 0`. The previous pairing —
   `target: 0` **with** `direction: "up"` — made the served `pace` identically
   zero for every window, which silently reduced NagLight's colour rule to a
   function of percent consumed. Measured on the wire 2026-09-12.
2. **Read `limits[]` for per-model usage.** Fable's weekly figure arrives only
   as `kind: "weekly_scoped"` with `scope.model.display_name`, sharing
   `resets_at` with the all-model weekly bucket; post it as a separate gauge.
   `severity` and `limits[].severity` are **still read and discarded** — the
   vendor's opinion of red is not NagLight's, and that part of LLR-005 is
   unchanged. Key on `display_name`; **never** on the payload's top-level
   codename keys (`nimbus_quill`, `cinder_cove`, …), which are unreleased-model
   placeholders whose names are not contractual.
3. **`weight_feeder.py` posts `favourable: "low"`** (IF-012 v1.1), so at-or-
   below-goal reads flat green while above goal still ramps to red.

**Baseline: this branch and the hub are in sync.** Verified 2026-09-12 —
`/opt/homehub/stack/ai-usage/ai_usage_feeder.py` is byte-identical to
`stack/ai-usage/ai_usage_feeder.py` on this branch (1644 lines), so the
2026-09-12 fixes landed here as well as on the hub: RFC3339 wire timestamps
(the contract declares `window.start`, `window.end` and `observed_at` as
strings, and the epoch integers the feeder used to post were refused with
`HTTP 400 cannot unmarshal number into Go struct field`), the matching
`is_fresh` read-back, `OPENCODE_TRUSTED_STATUSES` admitting `rate-limited`, and
`_OPENCODE_PROVIDER_IDS` accepting both `opencode-go` and `opencode`. **Start
the work above from this tree.** Re-verify the hub still matches before
deploying, since `/opt/homehub` is not a git checkout and has no history of its
own.
