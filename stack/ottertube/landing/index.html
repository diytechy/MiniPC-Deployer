Installing on Windows

  1. Download the file and keep it in a folder of its own on this computer (not on a network drive). It is a portable app: running it is the installation.
  2. Windows may say "Windows protected your PC". OtterTube is not signed with a Microsoft Authenticode certificate, so SmartScreen does not recognise it. Choose More info, then Run anyway. Do this only for a file downloaded from this page, on your home network.
  3. From then on OtterTube updates itself from this hub when it starts, and takes only an update signed with the household's update key.
